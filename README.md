# GBL Capital

Futures signals for NQ, ES, YM and RTY with a permanent record where losses can't be hidden.

- **Site:** https://eddyndumia.github.io/gbl-capital-app/
- **Downloads:** see [Releases](https://github.com/eddyndumia/gbl-capital-app/releases/latest)
- **Community:** [Discord](https://discord.gg/n9jqnd6Rq)

This repository holds the public launch site and the release downloads. The product source is private.

## What is in a release

| File | What it is |
| --- | --- |
| `gbl-capital-<version>.apk` | The customer app for Android |
| `gbl-desk-<version>.apk` | The trading desk app for GBL operators (needs an operator account) |
| `gbl-capital-web-<version>.zip` | The customer web app |
| `gbl-desk-web-<version>.zip` | The trading desk web app |
| `SHA256SUMS.txt` | Checksums for every file above |

## Installing the Android app

1. Download the `.apk` on your phone.
2. Open it. If Android asks, allow installs from your browser or file manager for this one install.
3. Open **GBL Capital**.

Verify a download before installing by comparing its SHA-256 with `SHA256SUMS.txt`.

## Version 1.2.0

The apps run on **sample data** in these public builds: no real signals, results or accounts. Both apps can connect to the real GBL APIs (live data mode is built and tested), which switches on once the backend is hosted.
